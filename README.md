AI-Powered Evangadi Forum

An AI-powered Q&A forum where users register, log in, post questions, and share answers. It also includes an AI assistant that answers questions using course documents through Retrieval-Augmented Generation (RAG).

Features
User registration and login (JWT authentication)
Post questions and submit answers
AI-powered assistant using course documents
RAG-based question answering
Questions and answers stored in a MySQL database
Tech Stack
Frontend: React
Backend: Node.js and Express
Database: MySQL
Authentication: JWT
AI: Retrieval-Augmented Generation (RAG)
Hosting: Frontend and backend deployed separately
