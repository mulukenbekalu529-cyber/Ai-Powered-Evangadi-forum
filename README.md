
**AI-Powered Evangadi Forum**

An AI-powered Q&A forum where users register, log in, post questions, and share answers. The application also features a RAG-based AI assistant that answers questions using course documents.

**Live Links**

App (vercel): https://ai-powered-evangadi-forum-gilt.vercel.app/

Backend API (Render): https://ai-powered-evangadi-backend-5lar.onrender.com

**Features**

User registration and login (JWT authentication) Post questions and submit answers AI-powered responses using course documents Questions and answers stored in a MySQL database

**Tech Stack**

Frontend: React Backend: Node.js and Express Database: MySQL AI: RAG-based assistant Authentication: JWT

**Note**

The backend is hosted on Render's free plan, so the first load can take some time.
